# Legacy exploratory images

These images predate the phase-3 data/schema corrections. Their original source
manifest was not saved, and the EDA script permits synthetic fallback data.
They are retained as historical exploratory work, not evidence for the corrected
held-out-device benchmark. Use `docs/benchmarks/` and its run manifests for
current measured results. Regenerate EDA with explicit data provenance before
using these images in a paper or feature-selection explanation.

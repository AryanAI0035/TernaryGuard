# Dashboard — future scope

Only frontend/backend directory placeholders exist. There is no shipped web interface, API, live alert feed or end-to-end network monitoring application here. The completed project can be built and validated without these directories or their prospective dependencies.

A future interface could replay collected benchmark and Nano results with their measurement scopes, display class-level weaknesses, and expose validated inference. Such work requires implementation and its own acceptance tests before it appears as a completed feature.
